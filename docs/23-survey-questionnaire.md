# CityWatch — Survey Questionnaire Templates

---

## 1. Pre-Development: Citizen Survey

**Purpose:** Validate the problem exists and understand citizen expectations.
**Target:** 30–50 local residents (friends, family, hostel mates, college staff)
**Method:** Google Forms / printed form

---

### Section A: Demographics

| Q# | Question | Type |
|---|---|---|
| A1 | Age group | Choice: 18-25 / 26-35 / 36-50 / 50+ |
| A2 | Do you own a smartphone? | Yes / No |
| A3 | How often do you use the internet daily? | Choice: <1hr / 1-3hr / 3-5hr / 5hr+ |
| A4 | Area of residence | Open text |

### Section B: Civic Issues Experience

| Q# | Question | Type |
|---|---|---|
| B1 | Have you ever faced a civic issue (pothole, garbage, broken streetlight, drainage) in your area? | Yes / No |
| B2 | If yes, which type of issue was most common? | Multi-choice: Pothole / Garbage / Streetlight / Drainage / Water / Other |
| B3 | Did you report the issue to anyone? | Yes (corporation) / Yes (local leader) / Yes (app) / No |
| B4 | If you didn't report, why? | Multi-choice: Didn't know where / Takes too long / Nothing happens / Complicated process |
| B5 | If you did report, was the issue resolved? | Yes (quickly) / Yes (slowly) / No / Don't know |
| B6 | How long did the resolution take? | Choice: <1 week / 1-4 weeks / 1-3 months / 3+ months / Never resolved |

### Section C: Platform Interest

| Q# | Question | Type |
|---|---|---|
| C1 | Would you use a web platform to report civic issues with photo evidence? | Definitely / Maybe / No |
| C2 | Would you be willing to take a photo of the issue using your phone camera? | Yes / No / Depends |
| C3 | Would you share your GPS location for automatic issue routing? | Yes / No / Only if anonymous |
| C4 | Would you like to track the status of your complaint online? | Yes / No |
| C5 | Would you want to see proof (photo) that the issue was fixed? | Yes / No |
| C6 | What categories of issues would you most want to report? | Multi-choice: Potholes / Garbage / Streetlights / Drainage / Water Supply / Illegal Construction / Other |
| C7 | What would make you NOT use such a platform? | Open text |

## 2. Pre-Development: Coordinator Feasibility Survey

**Purpose:** Test whether the coordinator middleman model is viable.
**Target:** 10–15 potential coordinators (college volunteers, local activists, NGO members)
**Method:** In-person interview / Google Forms

---

| Q# | Question | Type |
|---|---|---|
| D1 | Would you be willing to volunteer as a local area coordinator for civic issues? | Yes / Maybe / No |
| D2 | How many hours per week could you dedicate? | Choice: 1-2 / 3-5 / 5-10 / 10+ |
| D3 | Would you be comfortable visiting complaint locations to verify resolution? | Yes / Sometimes / No |
| D4 | Do you have a smartphone with GPS and camera? | Yes / No |
| D5 | Would you be willing to review complaints (photos + descriptions) and vote on their validity? | Yes / No |
| D6 | What concerns would you have about being a coordinator? | Open text |
| D7 | Would you prefer: fixed schedule or flexible? | Fixed / Flexible |
| D8 | What area/zone are you most familiar with? | Open text |

## 3. Post-Development: Usability Testing Survey

**Purpose:** Evaluate UI/UX after demo session.
**Target:** 10–15 testers (classmates, friends)
**Method:** Google Forms (after 15-min demo session)

---

### Section E: Overall Experience

| Q# | Question | Type |
|---|---|---|
| E1 | Rate the overall look and feel of the platform (1-5) | Scale 1-5 |
| E2 | Was the registration process easy? | Very easy / Easy / Okay / Difficult / Very difficult |
| E3 | Was the complaint submission wizard intuitive? | Very intuitive / Okay / Confusing |
| E4 | Did the camera capture work properly on your device? | Yes / No / Had issues |
| E5 | Did the GPS location capture work properly? | Yes / No / Inaccurate |
| E6 | Could you easily track the status of a complaint? | Yes / Somewhat / No |
| E7 | Was the notification system clear? | Yes / No |

### Section F: Feature Feedback

| Q# | Question | Type |
|---|---|---|
| F1 | Which feature did you find most useful? | Open text |
| F2 | Which feature was most confusing? | Open text |
| F3 | What feature is missing that you'd want? | Open text |
| F4 | Would you use this platform in real life? | Definitely / Maybe / No |
| F5 | Rate the map view (1-5) | Scale 1-5 |
| F6 | Rate the complaint detail page (1-5) | Scale 1-5 |
| F7 | Any bugs or issues you encountered? | Open text |
