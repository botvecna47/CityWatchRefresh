# CityWatch — Final Project Report

> This folder contains the chapters of your final project report.
> Each chapter is a separate file for easy editing.
> Combine them into a single document (Word/PDF) before submission.

---

## How to Use

1. Most chapters can be **copied directly** from your `docs/` folder
2. Add **screenshots** as you build the project (save in `Report/screenshots/`)
3. Add **code snippets** of important logic (not full files — highlight key methods)
4. Combine all chapters into one Word/PDF document before submission
5. Follow your college's report formatting guidelines (margins, fonts, page numbers)

---

## Tips for a Strong Report

- **Screenshots > Text**: Show the actual UI, not just describe it
- **Code snippets**: Show the Haversine formula, JWT filter, majority logic — not generic CRUD
- **Diagrams**: Copy from `docs/21-uml-diagrams.md` — recreate in draw.io if needed
- **Honest limitations**: Professors respect honesty about what you couldn't do
- **Future scope**: Shows you understand the bigger picture
